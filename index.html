PORTFOLIO ของผม: พงษ์นฤดล พูนจิรธนเรือง

ผมสนใจในการตั้งค่าและทดลองระบบต่าง ๆ เพื่อให้ได้ประสบการณ์จริงจากการสร้างเซิร์ฟเวอร์ การใช้งาน AI บนเว็บ และการจัดการเกมเซิร์ฟเวอร์

ลองแผงควบคุมจำลอง ดูโปรเจกต์ทั้งหมด

01 — เกี่ยวกับผม

ทำไมถึงเลือก CEDT

ผมเริ่มสนใจด้านนี้จากการต่อวงจร LED ตัวแรกแล้วมันไม่ติด ต้องนั่งไล่หาว่าขาไหนผิด จากตรงนั้นก็ค่อย ๆ ขยับมาเขียนโค้ดควบคุมเซนเซอร์ จนรู้ว่าสิ่งที่ชอบจริง ๆ คือจุดที่ฮาร์ดแวร์กับซอฟต์แวร์มาเจอกัน

วิศวกรรมคอมพิวเตอร์และเทคโนโลยีดิจิทัล (CEDT) เป็นหลักสูตรของคณะวิศวกรรมศาสตร์ จุฬาลงกรณ์มหาวิทยาลัย ที่ออกแบบมาให้เรียนแบบลงมือทำจริงตั้งแต่ปีแรก มีการฝึกงานทุกปีและทำงานร่วมกับบริษัทเทคโนโลยีชั้นนำตลอดหลักสูตร ซึ่งตรงกับสิ่งที่ผมอยากได้ คือได้ทดลองของจริง ไม่ใช่แค่ทฤษฎีในห้องเรียน

เป้าหมายของผมคือการเป็นวิศวกรที่ทำงานได้ตั้งแต่ระดับวงจรไปจนถึงระบบซอฟต์แวร์ที่คุยกับอุปกรณ์เหล่านั้น โดยเฉพาะสาย IoT และระบบฝังตัวที่เชื่อมโลกจริงกับข้อมูลดิจิทัลเข้าด้วยกัน

CEDT ในตัวเลข

  • รับนิสิตต่อปี300 คน
  • เทอมแรกไม่ตัดเกรด
  • ฝึกงานภาคอุตสาหกรรมทุกปี
  • กิจกรรมร่วมบริษัทFriday Activities

02 — SKILLS.BOM

ทักษะที่ติดตั้งแล้ว

เรียงเหมือนรายการอุปกรณ์บนแผงวงจร แต่ละแถวคือทักษะหนึ่งตัวที่ใช้ประกอบเป็นตัวผมตอนนี้

REFทักษะรายละเอียดระดับ
U1Python ใช้เขียนสคริปต์ประมวลผลข้อมูลจากเซนเซอร์และงานอัตโนมัติทั่วไป
U2C / C++ เขียนเฟิร์มแวร์ควบคุมไมโครคอนโทรลเลอร์ และ โปรแกรมต่างๆ
Q1ESP32 / Arduino ต่อวงจร อ่านค่าเซนเซอร์ สั่งงานอุปกรณ์ IoT
R1Git & GitHub จัดการเวอร์ชันโค้ดและทำงานร่วมกับผู้อื่น
C1วงจรไฟฟ้าต่างๆ อ่านผังวงจร ต่อเบรดบอร์ด แก้ปัญหาวงจรไฟฟ้าต่างๆ
D1การวิเคราะห์ข้อมูล แปลงข้อมูลดิบจากเซนเซอร์ให้อ่านง่ายด้วยกราฟ
U3Linux & Server ตั้งค่าและดูแลเซิร์ฟเวอร์บน Linux ใช้รัน service รับข้อมูลจากอุปกรณ์ IoT
