เริ่มชอบมาจากไหน

จาก Python ที่ยังอ่านไม่ออก มาเป็นชุด Arduino กล่องแรก แล้วไปจบที่ Linux

  1. 01 ตอนเด็ก

    ลองเขียน Python ครั้งแรก

    เคยลองเรียน Python ตั้งแต่ยังเด็ก แต่ตอนนั้นยังยากเกินไป เลยพักไว้ก่อน

  2. 02 ม.1 เทอม 1

    Arduino ครั้งแรก

    อบรม Arduino ที่โรงเรียนด้วย PictoBlox ที่เขียนโปรแกรมด้วยการต่อบล็อก ครั้งแรกที่โค้ดสั่งของจริงให้ขยับได้

  3. 03 ม.1

    ชุด Arduino กล่องแรก

    แม่ซื้อชุด Arduino ให้ เลยเลิกต่อบล็อกแล้วหัดเขียน C++ เองจากคลิป จนตอนนี้ C++ เป็นภาษาที่ถนัดที่สุด

  4. 04 ปิดเทอม ม.2

    ค่าย สอวน คอมพิวเตอร์ ค่ายแรก

    ได้เจอ Linux (Ubuntu) ครั้งแรกที่ค่าย แล้วเริ่มปรับแต่งเครื่องตัวเอง

  5. 05 หลังค่าย

    Linux ลึกกว่าที่คิด

    ลง Ubuntu ให้เพื่อน เพื่อนบอกว่า Arch เล่นเกมลื่นกว่า เลยลองลงเอง ลองไปหลายตัวจนกลับมาอยู่กับ Arch เพราะสะดวกและปรับแต่งได้ทุกอย่าง

    UbuntuArchFedoraArch + HyprlandManjaroArchBazziteUbuntuArch
  6. 06 ตอนนี้ · ม.3

    ค่าย สอวน รอบ 2

    ผ่านค่ายมาแล้ว 2 รอบ ระหว่างนั้นก็ทำโปรเจกต์ของตัวเองขึ้น GitHub ไปเรื่อย ๆ
